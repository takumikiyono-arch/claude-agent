# sales-meeting-prep（事前MTGメモ）

商談・面談の事前準備メモを「事前MTGメモ形式」で作成するスキル。

## 出力様式
- 必ず同梱の **`output-template.md` の構成（セクション順・見出し）に厳密に従う**。
- セクションを増減・改名しない。埋められない情報は `※要確認` と明記する（勝手に断定しない）。

## 進め方
1. **情報収集**：日時／場所／先方・当社参加者／目的／経緯／提案状況／外部環境／相手の組織・グループ構造を集める。足りなければユーザーにヒアリングする。
2. **テンプレを埋める**：`output-template.md` の各セクションに当てはめる。提案状況は「表（案件/プロダクト/ステータス/カウンターパート）＋案件別詳細」。アジェンダは時間配分つき。
3. **戦略的ポイントを設計**：
   - この面談で取りに行く「**握り**（意思決定事項）」を明確化する。
   - 提案仮説を立てたら**必ず批判的に検証**する（できること／まだ検証が要ることを切り分け、過大表現を避ける）。
   - ストーリーは「**外部環境 → 相手が中長期で目指す姿 → だからこの打ち手**」の順で接続する。
   - M&A・人事・組織再編などセンシティブな話題は「深入りしすぎない」留意を明記する。
4. **出典**を「情報ソース」に列挙する。

## 品質の基準
- 経営層向けは「現場ツール導入」ではなく「**経営アジェンダ**」の高さで書く。
- 事実と仮説を区別する。仮説は仮説と明記し、検証の余地を残す。

## 運用メモ
- 本スキルの `output-template.md` は、Notion「議事メモ」DB の事前MTGメモ
  （例：ヒューテックノオリン 経営企画役員面談 事前MTG）の様式に基づく**暫定版**。
- **正式テンプレートを受領したら `output-template.md` を差し替える**（このSKILL.mdは原則そのままでよい）。
